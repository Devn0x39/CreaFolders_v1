# CreaFolders_v1
CreaFolders is a lightweight and intuitive program. Its goal is to allow for the quick and organized creation of multiple folders directly on the user's desktop, in a simple, secure, and efficient way.

Automatic Language Detection:

CreaFolders features automatic detection of two operating system languages. Systems configured in Portuguese and English.

Main Features:

Choosing the Number of Folders

The user can select the number of folders to be created, with a controlled limit between 2 and 6 folders, the system validates the input to ensure that only valid values are accepted.  After selecting the quantity, the application opens a dedicated window for defining folder names.

Fields are generated dynamically. No field can be left blank. Navigation is fluid, with autofocus and support for the ENTER key.

Folders are created directly on the user's Desktop using native system functions. If a folder already exists, the process continues without error. The user receives confirmation at the end of the operation.

Dark Mode Interface:

The application uses a consistent dark theme, providing better visual comfort. Standardized dark background, high-contrast text, clean and organized interface and secondary windows with controlled focus.
